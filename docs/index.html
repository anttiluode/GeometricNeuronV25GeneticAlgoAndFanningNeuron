The biological matrix

branch b owns: route identity Δ-history e_fast e_medium e_slow local confidence over causal lifetime one global consequence × separated local causal state → branch-specific plasticity

The key architectural claim is not “neurons run GAs.” It is that physical compartmentalization can preserve causal address after global signals have mixed information.

What each gate removed

F2Only one route observable. Separation prevents silent damage to unseen routes.
F3Credit arrives late. Persistent local identity bridges the delay.
F4Reward loses its source label. Local eligibility rescues mixed global credit.
F5One memory constant fails. Useful causal lifetime depends on consequence timescale.
F6The branch selects its own memory lifetime and changes it after a hidden regime switch.

Claim boundary

These are synthetic learning experiments, not evidence that a dendrite or AIS implements this exact code. The F6 predictor bank is engineered. What has been earned is narrower: separated local state can solve credit problems that pooled state cannot, and local timescale choice can adapt when the temporal structure of consequence changes.

The next unresolved recursion is harder: can the available causal lifetimes themselves be grown and pruned instead of supplied in advance? A naive grow/prune attempt does not yet match F6, so that remains open rather than being tuned into a success.

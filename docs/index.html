V25 biological branch · F0–F5

Separation may be part of the learning rule.

The project started with genetic-algorithm fanning. The biological branch has now become more specific: semi-independent routes can preserve who changed and for how long that change remains eligible, even after downstream consequences have mixed into one global signal.

The current mechanism

local route perturbation ↓ local causal / eligibility state ↓ soma / AIS event and axonal fan-out ↓ recurrent downstream mixing ↓ one unlabeled scalar consequence × separate local eligibility traces ↓ route-specific plastic change

This is a synthetic learning architecture, not a claim that a neuron literally runs a genetic algorithm. The question is whether the physical separations already present in neurons could solve otherwise difficult credit-assignment problems.

Why this matters biologically

Aizenbud's dendritic picture gives semi-independent nonlinear subregions. Leterrier's AIS gives a sharp adaptive boundary and event generator. V25 adds a learning hypothesis: those separations can preserve local causal state after the global event has mixed information.

dendritic compartment ≠ merely one more feature possible additional role: preserve local ancestry / eligibility until delayed global consequence arrives

The hypothesis becomes stronger only if later gates can choose and adapt those local timescales without an experimenter picking them.

Next: the branch chooses its memory

F5 still selects the best eligibility decay after the fact. The next gate gives each branch several traces at once:

e_fast e_medium e_slow \ | / \ | / experience selects which causal memory to trust then change the downstream timescale mid-run

If trace preference follows the environment rather than staying fixed, the old V24 fast/medium/slow idea becomes an actual adaptive credit mechanism.

Claim boundary

The numerical gates are synthetic. They do not establish a specific molecular implementation, nor that dendrites or axons literally perform GA selection. What has been earned is narrower: local separation, route-specific causal state, and timescale can materially change learning under bounded and delayed feedback.

What the failure taught us

F8 matters as much as F9. A weighted mixture of two fixed resonators does not simply become a resonator at the intermediate frequency: the component phases separate over time. So a genuine adaptive spectral mechanism must change the dynamics themselves, not only reweight fixed outputs.

Claim boundary

These are synthetic credit-assignment experiments. V25 does not establish a biological oscillator, a literal genetic algorithm inside a neuron, or a complete spectral router. F9 earns a narrower result: in this off-grid toy, separated local state can use a mixed global consequence to search over and partially recover the temporal pole through which that branch's causal history is represented.

The next difficult test is multimodality: put two useful temporal modes on the same branch. If the mechanism always purifies to one winner, it is still too simple. A true route system sometimes has to preserve multiple temporal highways at once.

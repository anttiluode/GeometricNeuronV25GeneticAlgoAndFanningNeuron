The proposed repeating level

The claim worth testing is not “neurons are genes again.” It is that the organizational motif can repeat across scales whenever a system has branching alternatives, differential consequences, persistence, and another round of branching.

genetic scale: variation → selection → inheritance → biased future variation neuron-scale hypothesis: route fan → bottleneck / consequence → stabilization → changed future route fan V25 test: P₀ → P₁ → P₂ → … keep the whole population geometry, not only the winner candidate(g+1) = selected_center + successful_subspace · a + residual_noise

That makes the scientific question concrete: does history-conditioned population geometry outperform current-generation covariance, centroid momentum, isotropic mutation, and shuffled history when all arms get the same candidate and perturbation budget?

Claim boundary

This page is a hypothesis instrument. Biological neurons are not being claimed to run literal genetic algorithms, and fan-in/fan-out by itself is not evolution. The analogy becomes mechanistic only if alternatives persist across cycles, receive differential consequences, and successful route structure biases what is available next.

The first V25 centroid/DMD experiments are preserved in the repository as history. The restart begins from the population fan itself.
